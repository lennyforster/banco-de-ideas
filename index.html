Banco de ideas

Para abrir tus ideas en este dispositivo, pegá tu clave de GitHub. Se hace una sola vez por dispositivo.

Cómo crear la clave
  1. Entrá a github.com/settings/personal-access-tokens/new
  2. Nombre: Banco de ideas. Vencimiento: el más largo que te deje.
  3. Repository access: Only select repositories → el repo de datos de la persona.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copiala y pegala acá.

Importar de Google Keep
  1. Entrá a takeout.google.com con la cuenta de Google donde está tu Keep.
  2. Tocá Anular selección, bajá y marcá solo Keep.
  3. Siguiente paso → Crear exportación. Google te manda un mail con el .zip en unos minutos.
  4. Bajá el .zip y elegilo acá.
Cada nota pasa a ser un post-it, con su texto, listas, links e imágenes adentro. Las etiquetas de Keep pasan a ser categorías. La papelera no se importa.
